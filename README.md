# THE HIDDEN PROTOCOL

**Find the Clues. Crack the Codes. Capture the Flag.**

Welcome to THE HIDDEN PROTOCOL, a team-based forensic and cybersecurity CTF.

## About

- Team size: 3 participants
- Duration: Approximately 2 hours
- Platform: Windows
- Format: Sequential password-protected challenge packs
- Challenge style: Digital forensics, file analysis, metadata, hidden data, email forensics, OSINT, timeline analysis and case reconstruction

## How the Challenge Works

The challenge is sequential.

Start with **Q1.zip**.

The answer you obtain from a challenge is used to unlock the next challenge pack. Passwords are **case-sensitive** and must be entered exactly as instructed inside each challenge.

Do not brute-force ZIP passwords.

## Allowed

- Web browsers
- Search engines and OSINT resources where permitted
- 7-Zip
- CyberChef
- File and metadata analysis tools provided by the organizers
- Standard Windows utilities

## Not Allowed

- Generative AI tools
- Linux / Kali / WSL / virtual machines
- ZIP password brute-forcing
- Attacking or scanning external systems
- Attacking other teams or college infrastructure
- Sharing answers with other teams

## Important

All challenge evidence should be treated as investigation material for this event.

Do not upload challenge evidence to public file-sharing or analysis services.
